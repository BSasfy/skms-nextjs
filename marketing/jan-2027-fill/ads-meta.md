## Creative checklist

- [ ] Women: class photo or women training still + overlay text “Women only · Starts 7 Jan”
- [ ] Teens: kids/teens class action shot (faces OK only with consent) or venue exterior + “Trial £10”
- [ ] Adults: group class or pads work + “Beginners welcome · Trial £12”
- [ ] Logo / SKMS wordmark small in corner
- [ ] No fake urgency percentages; only real “limited places” / start date

## Ops notes

- If CTR drops after ~£10 spend, swap to the next ad variant (don’t raise budget).
- Turn on WhatsApp/Messages if available — many parents and women prefer DM.
- Pause women campaign once ~20 SumUp bookings confirmed.
- Check link destinations once before launch (broken `/beginners` links are fixed on-site).
